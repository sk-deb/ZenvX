// core features

Built different.
By design.

Every decision in ZenvX starts with one question: does this respect the user? If the answer is no, it doesn't ship.

🔒
Zero Telemetry
No crash reports phoning home. No usage analytics. No "improvement programs." Your activity stays on your machine, period.
🛡️
System-wide Ad Block
Network-level blocking built into the OS itself — not just the browser. Every app, every request, filtered before it even leaves your machine.
🔐
Hardened by Default
AppArmor profiles, encrypted DNS-over-HTTPS, firewall active on first boot. Security isn't a setting you enable — it's the default state.
🤖
Local AI, No Cloud
Ollama-powered local LLM assistant built in. Ask questions, run commands, get help — entirely on your hardware. Your data never leaves.
⚡
Debian Stable Core
Built on Debian 13 — the rock-solid foundation trusted by millions. ZenvX adds the privacy layer, not a custom kernel rabbit hole.
🎨
Modern UI, No Bloat
A custom GNOME experience that looks premium and loads fast. No preloaded junk apps. Install what you actually want — nothing more.

How we're
building this.

ZenvX is being built in public. Every milestone is community-tested before release.

Phase 0 — Done
Foundation & Vision
Architecture defined. Debian 13 base selected. Privacy threat model documented. Repository initialized.
Phase 1 — In Progress
Core Privacy Layer
System-wide DNS-over-HTTPS. Network-level ad/tracker blocking. AppArmor hardening profiles. Telemetry audit tools.
Phase 2 — Q3 2026
ZenvX Desktop Experience
Custom GNOME theme. First-boot privacy wizard. App store (FOSS-only by default). Brave browser pre-configured.
Phase 3 — Q4 2026
Local AI Integration
Ollama bundled. System assistant that runs 100% on-device. No API keys, no cloud dependency.
Phase 4 — 2027
ZenvX 1.0 Stable
Full installer. Hardware compatibility verified. Community LTS support. Enterprise edition launch.
